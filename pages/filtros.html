O que é filtragem de imagem?

Alteração dos pixels

Um filtro digital é uma operação aplicada aos pixels de uma imagem. Dependendo do algoritmo, podemos modificar cores, luminosidade, contraste ou até destacar contornos.

Alguns filtros analisam cada pixel separadamente. Outros consideram também os pixels vizinhos por meio de uma matriz chamada kernel.

CLASSIFICAÇÃO

Como os filtros funcionam?

PONTO A PONTO

Filtros de cor

Modificam cada pixel individualmente, sem precisar analisar os pixels vizinhos.

  • Escala de cinza
  • Negativo
  • Brilho e contraste
  • Separação RGB
KERNEL

Filtros espaciais

Utilizam uma pequena matriz para calcular o novo valor com base nos pixels próximos.

  • Desfoque
  • Nitidez
  • Detecção de bordas
