CONCEITO

O que é filtragem de imagem?

Alteração dos pixels

Um filtro digital é uma operação que analisa ou modifica os valores dos pixels de uma imagem. Dependendo da regra aplicada, podemos mudar as cores, ajustar a luminosidade ou destacar bordas.

Alguns filtros trabalham com cada pixel individualmente. Outros calculam um novo valor usando também os pixels ao redor, em uma operação chamada convolução.

Nesta página, a imagem original permanece como referência. Cada filtro é calculado a partir dela, permitindo comparar os resultados sem acumular alterações sucessivas.

filtro_cinza.js

> cinza = 0.299 × R

> + 0.587 × G

> + 0.114 × B

i

Na escala de cinza, os três canais recebem o mesmo valor calculado. O verde tem peso maior nessa fórmula porque contribui mais para a percepção de luminosidade usada por esse modelo de conversão.

CLASSIFICAÇÃO

Como os filtros funcionam?

PONTO A PONTO

Filtros de cor

Calculam um novo valor a partir dos canais do próprio pixel, sem consultar seus vizinhos.

  • Escala de cinza
  • Negativo
  • Brilho e contraste
  • Separação RGB
KERNEL

Filtros espaciais

Usam uma pequena matriz de pesos para combinar o pixel atual com os pixels ao redor.

  • Desfoque
  • Nitidez
  • Detecção de bordas
EXEMPLO DE KERNEL

Detecção de bordas

-1 -1 -1 -1 8 -1 -1 -1 -1
i

No desfoque, os nove pesos do kernel são iguais a 1/9: o resultado é a média de uma vizinhança de 3 × 3 pixels. Já o kernel acima realça diferenças entre o centro e seus vizinhos, destacando mudanças bruscas de intensidade que podem representar bordas.

CÓDIGO E APLICAÇÕES

Da teoria à prática

Um trecho do algoritmo

O filtro de cinza calcula uma intensidade a partir dos três canais. Em seguida, atribui essa intensidade a R, G e B. 

const cinza =
    0.299 * vermelho +
    0.587 * verde +
    0.114 * azul;

pixels[indice] = cinza;       // R
pixels[indice + 1] = cinza;   // G
pixels[indice + 2] = cinza;   // B

Esse trecho resume a lógica usada no arquivo js/filtros.js. O Canvas permite ler os dados dos pixels, modificar seus canais e desenhar o resultado na tela.

Onde filtros são úteis?

Fotografia: ajuste de brilho, contraste e aparência da imagem.

Documentos digitalizados: conversão para preto e branco para facilitar a visualização de certos textos.

Visão computacional: destaque de contornos como uma etapa preliminar de análise.

Imagens científicas: realce de características que depois precisam ser avaliadas no contexto correto.

!

Um filtro muda os dados da imagem; não cria detalhes que não estavam presentes na captura. Além disso, aplicar um filtro depois de esconder uma mensagem por LSB pode modificar seus bits e impedir a extração.
