CONCEITO INICIAL

Uma imagem é uma matriz de pixels

O que é um pixel?

Pixel é a menor unidade visível de uma imagem digital. Cada pixel armazena informações que determinam a cor exibida naquela posição.

Quando milhares ou milhões de pixels são organizados lado a lado, nossos olhos interpretam o conjunto como uma imagem contínua.

pixel_information.txt

> posição: (120, 85)

> vermelho: 0–255

> verde: 0–255

> azul: 0–255

[OK] Cor pronta para exibição.

!

A palavra pixel surgiu da expressão inglesa picture element, que significa “elemento de imagem”.

02
DIMENSÕES

Resolução e quantidade de pixels

1920 × 1080 = 2.073.600 pixels

A resolução informa quantos pixels existem na largura e na altura de uma imagem.

Uma imagem com resolução de 1920 × 1080 possui 1.920 pixels em cada linha e 1.080 pixels em cada coluna.

Quanto maior a quantidade de pixels, maior pode ser o nível de detalhe, embora isso também aumente o tamanho do arquivo.

05
REPRESENTAÇÃO BINÁRIA

Dos valores RGB aos bits

Por que os bits importam?

Computadores armazenam informações utilizando valores binários: zero e um. Um valor RGB entre 0 e 255 pode ser representado por oito bits.

A esteganografia LSB modifica o último bit desses valores para armazenar informações com alterações visuais praticamente imperceptíveis.

VALOR ORIGINAL 11001010 202
→
BIT MODIFICADO 11001011 203
i

A diferença entre 202 e 203 é pequena demais para causar uma mudança visual facilmente perceptível, mas já permite armazenar um bit da mensagem.

06
FORMATOS DE ARQUIVO

Por que usaremos imagens PNG?

RECOMENDADO

PNG

Utiliza compressão sem perdas, preservando os valores dos pixels e os bits da mensagem escondida.

  • Preserva os pixels
  • Suporta transparência
  • Adequado para LSB
CUIDADO

JPEG

Utiliza compressão com perdas e pode alterar os pixels, destruindo ou corrompendo a mensagem escondida.

  • Arquivo geralmente menor
  • Descarta informações
  • Inadequado para nosso método
