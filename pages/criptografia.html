01
FUNDAMENTAÇÃO

O que é criptografia?

Proteção do conteúdo

Criptografia transforma uma informação legível, chamada texto original, em dados cifrados. Para recuperar a informação, é necessário executar a operação inversa com a chave apropriada.

Neste laboratório usamos criptografia simétrica: a mesma chave serve para criptografar e descriptografar. O usuário informa uma senha, e o sistema deriva dela a chave que será usada pelo AES-GCM.

Ter o texto cifrado não é suficiente para revelar a mensagem. A proteção, porém, também depende de escolher e preservar uma senha adequada.

ENTRADA Mensagem secreta
↓
ALGORITMO + CHAVE AES-GCM
↓
SAÍDA Dados cifrados
!

A criptografia protege o conteúdo, mas não esconde que existem dados cifrados. No próximo módulo, a esteganografia mostrará como ocultar esses dados dentro de uma imagem.

ELEMENTOS

Partes do processo criptográfico

01

Texto original

Mensagem legível antes de ser processada pelo algoritmo de criptografia.

Olá, esta mensagem é secreta.
02

Senha e chave

A senha é digitada pelo usuário; a chave de 256 bits é derivada dela pelo PBKDF2.

Senha → PBKDF2 → chave AES
03

Texto cifrado

Dados produzidos pelo AES-GCM, que não podem ser lidos como a mensagem original.

eyJ2ZXJzaW9uIjox...
i

O texto mostrado no resultado é codificado em Base64 para facilitar a cópia. Base64 não é criptografia: a proteção é realizada pelo AES-GCM antes dessa representação em texto.

04
IMPLEMENTAÇÃO

O que acontece no laboratório?

01

Salt aleatório

Um salt novo é gerado para cada operação. Ele participa da derivação da chave e não precisa ser mantido em segredo.

02

Derivação da chave

O PBKDF2 combina senha e salt para derivar uma chave AES de 256 bits.

03

Criptografia autenticada

O AES-GCM cifra a mensagem e verifica se a senha e os dados apresentados são compatíveis.

04

Pacote final

O resultado inclui salt, IV e dados cifrados. Essas informações permitem tentar a recuperação com a senha correta.

i

O IV é um valor de inicialização gerado aleatoriamente para a operação AES-GCM. Assim como o salt, ele acompanha o resultado e não é a senha. A senha não aparece nesse pacote.

05
CÓDIGO E APLICAÇÕES

Onde essa proteção é útil?

A operação no JavaScript

Após derivar a chave a partir da senha, o navegador usa a Web Crypto API para cifrar os bytes da mensagem: 

const dadosCifrados =
    await crypto.subtle.encrypt(
        {
            name: "AES-GCM",
            iv: vetorInicializacao
        },
        chaveDerivada,
        new TextEncoder().encode(mensagem)
    );

O trecho representa a etapa de cifragem implementada em js/criptografia.js. Na operação inversa, o navegador usa crypto.subtle.decrypt().

Aplicações e limites

Criptografia é usada para proteger informações em comunicação digital e armazenamento de dados. No nosso projeto, ela protege uma mensagem antes de inseri-la na imagem.

Uma senha curta ou previsível enfraquece a proteção. Além disso, criptografar não impede que alguém veja, copie ou apague os dados cifrados.

Por isso, este laboratório é uma demonstração educacional: ele explica princípios importantes, mas não substitui uma solução profissional para armazenar documentos sensíveis.
