ANTES DE COMEÇAR

O que vamos testar?

Este laboratório combina duas técnicas com funções diferentes. Primeiro, a criptografia transforma o texto em dados que dependem da senha para serem recuperados. Depois, a esteganografia insere esses dados nos pixels de uma imagem.

Criptografia: proteger o conteúdo

O AES-GCM transforma a mensagem em dados cifrados. A mesma senha utilizada na proteção será necessária para descriptografá-los durante a recuperação.

Uma senha curta ou previsível diminui a proteção prática. A barra exibida no formulário oferece uma orientação, mas não garante que uma senha seja impossível de descobrir.

Esteganografia: ocultar os dados

Após a criptografia, os dados resultantes são distribuídos pelos bits menos significativos dos canais RGB. A imagem de saída é salva em PNG para preservar os valores dos pixels.

Ocultar dados não torna sua presença indetectável. As duas técnicas se complementam: uma protege a leitura da mensagem, e a outra a insere no suporte visual.

IMPORTANTE

Como preservar a mensagem?

[PNG]

Mantenha o formato

Você pode usar PNG, JPEG ou WEBP como imagem de entrada, mas não converta o resultado baixado para JPEG. Essa conversão pode modificar os bits da mensagem.

[PIXEL]

Não edite a imagem

Recortes, filtros, redimensionamentos e algumas plataformas de compartilhamento podem modificar os pixels utilizados pelo laboratório.

[KEY]

Guarde a senha

O PixelCipher Lab não armazena nem consegue recuperar senhas esquecidas. Sem a senha correta, a mensagem protegida não poderá ser lida pelo laboratório.

Qual imagem escolher?

Uma imagem com mais pixels oferece mais espaço para inserir dados. Observe a capacidade indicada após selecioná-la e escolha um arquivo sobre o qual você tenha direito de uso.

O que esconder na demonstração?

Para apresentar o projeto, uma frase curta, uma pergunta ou uma pista para a atividade é suficiente. Evite inserir dados sensíveis em uma demonstração pública.
